KAY POS Rust 0.2.13 for Windows x64.

- Sale Summary > Categories (Sales): double-click a category row, or click its name, to view receipts for that category within the selected date range. The list supports pagination and receipt detail viewing. Category matching follows the summary's grouping, including legacy names; receipts are not duplicated by multiple item lines.
- Fixed category receipt detail remaining on Loading receipt after the data arrived. Category and receipt links now use a rounded filled hover style.
- Kay Assistant understands category inventory requests such as ရေခဲမုန့် လက်ကျန် ပြပေးပါ, and category best-seller requests such as ရေခဲမုန့် ရောင်းအားအကောင်းဆုံးကို ပြပေးပါ. Best sellers are ranked by allocated sales revenue, not quantity.
- Added current category list queries and Supplier searches by name, phone, company or contact person, with supplier detail dialogs and existing permissions retained.
- Sale saved dialog: removed the bottom Close control; Enter closes the dialog. The top Close control uses a plain icon with color-only hover feedback.

POS-only mode remains enabled. No database migration is included. Existing database configuration and shop data are preserved.

Finish sales and sign out, then use Settings > App Updates or Check for Updates on the login screen. For manual installation, close KAY POS and extract the signed ZIP into the existing client folder, preserving configuration files.
