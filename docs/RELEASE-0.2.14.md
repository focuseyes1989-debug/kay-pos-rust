KAY POS Rust 0.2.14 for Windows x64.

- Receipt editor: configurable thermal paper widths including 58/80/112 mm and custom widths, margins, proportional logo sizing, fonts and spacing; reusable layouts, field visibility/order, item columns and drag/keyboard reordering. Preview and printing share the layout. Wider receipt preview fits 112 mm paper.
- Search suggestions with debouncing, keyboard and touch support, using already-loaded authorized results.
- Kay Assistant: payment-method sales, separate KPay accounts (including KPay(889) and KPay(510)), combined KPay totals, filtered receipts, Parent-category sales and expense-category summaries. Added Burmese income/expense wording aliases and preserved date/payment follow-ups.
- Appearance: compact two-column color controls and live preview; configurable icon hover colors for menu actions and dialog/sidebar close controls.
- Header uses the saved receipt logo. Sidebar shows the signed-in user's photo, username and role, with Sign out always visible below the scrolling navigation.
- Users settings permission checks tightened, including server-side administrator checks for user listing.

POS-only mode remains enabled. No database migration is included. Existing database configuration and shop data are preserved. Appearance preferences remain local to each client.

Finish sales and sign out, then use Settings > App Updates or Check for Updates on the login screen. For manual installation, close KAY POS and extract the signed ZIP into the existing client folder, preserving configuration files.
