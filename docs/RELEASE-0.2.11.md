KAY POS Rust 0.2.11 for Windows x64.

- Refreshed Dashboard summary cards, daily sales and period comparison charts, date shortcuts, and balance/stock panels.
- Expenses open on Today, with a live category filter and combined category totals. Spending by Category and Expense History use separate tabs; selecting a chart category opens its history.
- Live search across Customers, Suppliers, Inventory, Locations and Expenses. Database searches in Service Orders and Activity Log wait 300ms after typing and cancel superseded requests.
- Consistent searchable dropdowns throughout the client, with clear icons removed and Employee/Attendance filters aligned on desktop.
- Improved Myanmar font fallback, line spacing, inputs and tables; aligned header controls and content-sized category cards.
- Simplified Settings overview and improved expense list spacing.

POS-only mode remains enabled. This update contains no database migration and preserves the client's database configuration and shop data.

Install through Settings > App Updates. Finish sales and sign out before installation. Alternatively, close KAY POS and extract the signed ZIP into the existing client folder, keeping the existing configuration files.
