# KAY POS 0.2.8

This Windows x64 release expands the PostgreSQL-backed Rust client and refreshes its day-to-day workflows.

- Adds purchases, discounts, expense management, held sales, loyalty, reports, activity, category groups, and compatibility tools.
- Adds a PostgreSQL-backed AI page with safe read-only queries, relative date requests, permission checks, audit logging, and Burmese answers with English digits.
- Aligns management pages with the Receipts and Inventory workspace, including a two-column Expense history and detail view.
- Moves Hold sale and Held sales into the Cart header as compact icon actions.
- Improves checkout recovery, stock and service-order validation, product metadata, receipt preview, and shared desktop controls.

Before rollout, back up the PostgreSQL database and apply the repository migrations required by the enabled features. The updater does not run database migrations automatically. Finish active sales, sign out, and install from the login screen. Pilot on one client before wider deployment.
