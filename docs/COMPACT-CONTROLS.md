# Compact controls

The final shared stylesheet, assets/compact-controls.css, sets normal single-line inputs, selects, searchable comboboxes and action buttons to a 36px minimum. Controls retain 14px Myanmar text with 1.8 line height and 4px vertical padding. Search wrappers use the same height. Text buttons and combobox options can grow for wrapped content. Product/list cards, image controls, calendar days, drag grips, color swatches and icon-only close/header controls keep their specialized layouts. Multi-line category labels remain content-sized. Textareas retain room for multiple lines.

Verification: browser computed-size checks for login inputs, expense search/filter, searchable combos, catalog search and transfer buttons; multi-line category growth; desktop compilation.
